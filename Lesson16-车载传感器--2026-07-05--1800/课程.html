车载传感器标定——让所有传感器"看向"同一个世界

← 上一课 ☰ 目录 下一课 →

一、先想想这个问题

你的车上有 8 个摄像头、5 个毫米波雷达、1 个激光雷达、12 个超声波雷达——它们各自看到的"世界"是一样的吗？

答案是：不一样。

同一个行人站在车右前方 3 米处，摄像头"看到"的是 1920×1080 像素平面上的一个图像区域（x=1200, y=600），激光雷达"看到"的是三维点云中的一堆点（X=2.5m, Y=1.8m, Z=1.6m），毫米波雷达"看到"的是另一个坐标系中一个模糊的回波信号。

核心问题：不同传感器看到的"同一个物体"，在各自的坐标系里位置完全不同。怎么让这些数据"对齐"，让车的大脑知道它们说的都是同一件事？

答案就是——传感器标定（Sensor Calibration）：通过数学计算，把不同传感器的坐标系"对齐"到同一个世界坐标系中。

二、传感器标定的两类"对齐"

传感器标定分为两大部分：自己内部对齐（内参） 和 彼此之间对齐（外参）。

类型英文解决什么问题类比
内参标定Intrinsic Calibration单个传感器本身的测量偏差（畸变、偏移、焦距偏差等）给每个人的眼睛各自配眼镜——先让"自己"看清楚
外参标定Extrinsic Calibration不同传感器之间的空间位置和姿态关系（旋转、平移）让大家站成一排、面向同一个方向——坐标系统一

内参标定：先让"自己"看清楚

以摄像头为例——镜头不是完美的。广角镜头会引入桶形畸变或枕形畸变，镜头中心和感光芯片中心可能不对齐，焦距也会受制造公差影响。

真实世界直线 → 镜头 → 畸变弯曲的像 → 畸变矫正 → 矫正后的直线图像

张正友标定法（Zhang's Method）——最经典的摄像头内参标定方法：

  1. 打印一张棋盘格标定板（黑白格子相同）
  2. 用摄像头从不同角度拍 10~20 张照片
  3. 检测每张照片中的角点（格子交叉点）
  4. 利用角点在"像素坐标"和"世界物理坐标"之间的对应关系，计算 5 个内参：
    • 焦距（fx, fy）——两个方向
    • 主点偏移（cx, cy）——光轴中心偏离
    • 畸变系数（k1, k2, k3, p1, p2）
  5. 以后拍的所有照片，直接用这组参数做畸变校正

💡 每次生产下线的摄像头，畸变参数都不一样——因为每个镜头的制造公差是随机的。所以每颗摄像头必须独立标定。

外参标定：让传感器彼此"对齐"

外参标定解决的是：不同传感器的坐标系之间的转换关系。

         激光雷达坐标系                  摄像头坐标系
       (X_L, Y_L, Z_L)               (X_C, Y_C, Z_C)
             │                              │
             │  旋转矩阵 R (3×3)            │
             │  + 平移向量 T (3×1)          │
             │                              │
             └──────────→ 统一世界坐标系 ←──┘
                     (X_W, Y_W, Z_W)

外参 = [R | T] — 一个 3×4 的矩阵，告诉系统"激光雷达看到的点，站在摄像头位置上应该在哪"。

三、多传感器联合标定——实际操作

实际量产中，一辆车需要做多传感器联合标定：

步骤

步骤做什么工具精度要求
1. 确定标定场在车间内布置已知位置的特征物（棋盘格、角反射器、ArUco 码）高精度测量仪、全站仪±1mm
2. 单独标内参每个摄像头独立跑张正友标定棋盘格标定板亚像素级
3. 联合标外参所有传感器同时观测同一特征物，计算两两之间的 [R|T]专用标定软件±2mm / ±0.1°
4. 验证放一个目标物在不同位置，检查各传感器检测结果是否映射到同一坐标验收测试< 5cm 偏差
5. 固化参数将标定参数写入各 ECU 的固件/配置文件中刷写工具—

四、时间同步——比空间对齐更难的问题

空间对齐了，但如果时间对不上，一切等于白做。

传感器帧率每帧时间问题
摄像头30 fps33 ms曝光时间、读出时间不同步
激光雷达10~20 fps50~100 ms旋转扫描一圈需要时间
毫米波雷达20 fps50 ms数据处理延迟不定
超声波雷达~10 fps~100 ms声波往返时间本身就慢

时间不同步的后果： 摄像头拍到的是"行人 33ms 前的位置"，而激光雷达看到的是同一个行人"100ms 前的位置"——车在 100km/h 时，0.1 秒已经跑了 2.8 米！如果不做时间对齐，融合系统会把"两个不同时空的行人"当成两个不同的物体。

三种同步方案

方案精度实现方式适用场景

PTP 时间同步（IEEE 1588）< 10 μs以太网上精确时间协议，主时钟广播时间戳车载以太网连接的传感器

五、在线自标定——出厂后还能自动修正

标定不是"一次做完管一辈子"的。行驶中的振动、碰撞、温度变化、零部件疲劳都会导致传感器位置偏移。

偏移来源典型偏移量后果
车辆颠簸0.1°~0.5°车道保持偏左/偏右 10~30cm
更换前挡风玻璃1°~3°前视摄像头完全偏离，ADAS 误报
保险杠碰撞（轻微）2~5 mm雷达探测角度误差
温度热膨胀0.05°/10°C长期累积不可忽视

在线自标定（Online Self-Calibration） 技术应运而生：

  • 利用行驶中已知特征（车道线、路沿、静止车辆、建筑物边缘）自动重新计算外参
  • 特斯拉 FSD 就是典型的在线自标定系统——摄像头检测到车道线偏离中心超过某个阈值 → 自动触发标定算法修正外参
  • 一般结合 SLAM（同时定位与建图）技术，一边建地图一边修正传感器偏差

💡 这就是为什么校准后的 ADAS 系统需要在特定路线上"学习"一段时间——车在行驶中不断修正传感器之间的微小偏移。

六、三条核心规则

#规则一句话
1标定是传感器融合的"地基"内参不准→外参错位→融合数据全都是噪声，上层算法再好也白搭
2空间对齐和时间同步缺一不可空间标定只解决"它们在哪儿"，时间同步解决"它们什么时候看到的"——两者都错了等于数据全废
3标定不是一次性的——在线自标定是刚需振动、碰撞、温度变化都会导致参数偏移；量产车必须在日常行驶中持续自标定，否则 ADAS 精度随里程下降
