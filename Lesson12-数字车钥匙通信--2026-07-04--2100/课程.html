UWB精确测距——手机怎么知道它离车正好1.2米？

← 上一课 ☰ 目录 下一课 →

一、先想想这个问题

你的手机在口袋里，你走到驾驶座门前——车门自动解锁了。但你绕到车尾去拿后备箱的东西，车门不会解锁。

问题：车怎么知道你站在驾驶座门口，而不是后备箱位置？

你可能猜到了——靠 UWB（超宽带）测距。但是：

为什么 UWB 能精确到 ±10 厘米，而蓝牙（BLE）只能告诉你"在附近"？它们测距的原理到底有什么本质不同？

这就是今天要讲的核心：UWB 的精确测距原理。

二、两种测距思路：看强度 vs 算时间

2.1 BLE：看信号有多强（RSSI）

BLE 测距的方法非常简单——看信号强度（RSSI，Received Signal Strength Indicator）。

原理：信号在空气中传播会衰减，距离越远信号越弱。如果我知道你出发时的信号强度，我就根据收到的信号强度反推距离。

因素对 BLE 测距的影响
人体阻挡手机放口袋 vs 拿手里，信号差 5~15 dB
多径反射信号打到墙上反射过来，让你以为"信号不错"
天线方向手机天线朝向不同，信号强度变化很大
温度/湿度空气条件变化也会影响信号衰减
结果：BLE 的 RSSI 测距误差通常在 3~5 米，甚至更差。它只能告诉你"人在附近"，精确不到"站在哪个门旁边"。

2.2 UWB：算信号飞了多长时间（ToF / TWR）

UWB 用的方法完全不同——它不关心信号有多强，只关心信号飞了多久。

原理很简单：如果你知道光速（≈ 30 万公里/秒），又知道信号从发出到接收用了多少时间，那么：

距离 = 光速 × 时间 ÷ 2（除以 2 是因为信号"去 + 回"是两倍距离）

UWB 测距流程（双向测距 Two-Way Ranging, TWR）：

手机                    车
 |                       |
 |--- 测距请求 --->------|  手机发出脉冲
 |                       |  车收到后等待固定时间 T_reply
 |<--- 测距响应 ---------|  车回复脉冲
 |                       |
 | 手机计算：总时间 - T_reply = 2 × 飞行时间
 | 飞行时间 × 光速 ÷ 2 = 距离

UWB 能精确的关键原因：

特性为什么重要
带宽极大（500 MHz+）脉冲极短（~2 纳秒），时间分辨率高
时间戳精度达到皮秒级能测到 1 纳秒以内的飞行时间差
不受多径干扰首径（第一条到达的路径）容易被识别，滤掉反射信号
不受信号强度影响不依赖 RSSI，人体阻挡和方向不影响测距精度

一个比喻：BLE 像蒙着眼睛听脚步声大小判断距离，UWB 像用秒表精确测量回声返回的时间。

三、UWB 如何防"中继攻击"？

3.1 什么是中继攻击

回忆 Lesson 06 提到的问题：有人拿两个中继器，一个靠近你的手机，一个靠近车，把信号"接力"传过去——让车以为你就在旁边。

中继攻击示意图：
攻击者 A              攻击者 B
（靠近你手机）         （靠近车）
     |                     |
📱 ---|<-- 转发信号 --->|--- 🚗
你在家里                车以为你在旁边

3.2 UWB 为什么天然防中继

UWB 的双向测距（TWR）天然防中继，原因很简单：

  1. UWB 测的是往返时间——手机发请求→车响应→手机收到，整个过程有严格的时间窗口
  2. 中继器会引入额外延迟——每个中继器至少要几十微秒来处理和转发信号
  3. UWB 能检测到这个异常延迟——如果收到的响应时间比预期长太多，说明信号被人截路了

关键理解：中继器可以在 10 微秒内转发 BLE 信号（BLE 的时间精度不够，看不出异常），但 UWB 的测距精度是纳秒级的——多出 1 微秒的延迟等于 300 米的距离差，一眼就能看出问题。

CCC（Car Connectivity Consortium）Digital Key 3.0 标准要求：无感进入必须使用 UWB 安全测距，仅靠 BLE 不足以达到安全要求。

四、三条核心规则

#规则一句话
1UWB 靠时间算距离，不是靠信号强度BLE 看 RSSI（信号强弱），UWB 算 ToF（飞行时间），这是本质差异
2UWB 的精度来自大带宽和纳秒级脉冲带宽越大 → 脉冲越短 → 时间分辨率越高 → 距离越准
3UWB 的双向测距天然防中继攻击中继器带来的额外延迟在纳秒精度下一目了然
