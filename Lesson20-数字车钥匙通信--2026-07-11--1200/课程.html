中继攻击（Relay Attack）——为什么手机靠近才能开车门？

← 上一课 ☰ 目录 下一课 →

一、先想想这个问题

你晚上把车停在小区楼下，锁好车，上楼回家睡觉。第二天早上发现车不见了——监控显示凌晨三点，有个人拿着一个小盒子站在车旁边，另一个人拿着另一个小盒子站在你家门口，车就这么"自己"解锁、点火、开走了。

你的车钥匙明明放在客厅桌上！他们是怎么做到的？

这不是科幻片。这是真实存在的中继攻击（Relay Attack）——一种专门对付无钥匙进入系统（PKE/PEPS）的攻击方法。

二、中继攻击的原理——两个小偷"接力"偷车

传统的遥控钥匙（RKE）按一下按钮才开门，攻击难度大。但无钥匙进入（PKE/PEPS）为了便利——钥匙放口袋、靠近车门自动解锁——反而引入了一个致命弱点：

系统只验证"钥匙是否在附近"，但不验证"有多近"。

攻击流程：

  1. 小偷甲拿着一个信号放大器站在你家门口（或窗外），捕捉钥匙发出的微弱射频信号
  2. 放大器把信号通过无线中继（可以是几公里外的互联网）传给小偷乙
  3. 小偷乙拿着另一个放大器站在车旁，把信号"播放"出去
  4. 车以为钥匙就在旁边 → 解锁 → 点火 → 开走

关键点：小偷不需要知道钥匙的加密算法，不需要破解密码——他们只是忠实地"转发"信号。车和钥匙之间的加密通信仍然正常工作，只是通信路径被人为拉长了。

三、为什么传统 RKE/PKE 挡不住中继攻击？

系统工作原理能否防中继攻击？原因
RKE（遥控钥匙）按按钮→发送固定/滚动码→解锁✅ 基本安全需要用户主动按按钮，攻击窗口小
PKE/PEPS（无钥匙进入）靠近→LF唤醒→双向认证→解锁❌ 极度脆弱钥匙被动响应，攻击者只需转发信号
手机数字钥匙（仅BLE）BLE广播→手机唤醒→认证→解锁❌ 同样脆弱BLE 信号可被中继，无法测距
手机数字钥匙（BLE+UWB）BLE唤醒+UWB测距→认证→解锁✅ 安全UWB可精确测量距离（厘米级），中继攻击会暴露

传统无钥匙系统为什么防不住？

  • LF（低频，125kHz）唤醒信号穿墙能力强——小偷在门外就能唤醒客厅桌上的钥匙
  • 射频响应信号（315/433MHz或868MHz）传输距离远——被中继后还能正常工作
  • 系统没有距离验证机制——它只问"你是不是对的钥匙"，不问"你在多远"

四、UWB 如何终结中继攻击？

UWB（超宽带，Ultra-Wideband） 的核心能力不是通信速度，而是精确测距。

图 2 — UWB 双边双向测距（DS-TWR）

sequenceDiagram participant CAR as 车辆 UWB 锚点 participant KEY as 手机/钥匙 UWB 芯片 Note over CAR,KEY: 1. 车辆发送 Poll 包，记录发送时间 T1 CAR->>KEY: Poll (T1) Note over KEY: 2. 钥匙收到 Poll，记录到达时间 T2 Note over KEY: 3. 钥匙稍后发送 Response，记录 T3 KEY->>CAR: Response (T3 + T2) Note over CAR: 4. 车辆收到 Response，记录到达时间 T4 Note over CAR,KEY: 5. 车辆计算飞行时间：
ToF = [(T4-T1) - (T3-T2)] / 2 Note over CAR: 6. 距离 = ToF × 光速
如果距离 < 2米 → 解锁
如果距离 > 5米 → 拒绝

UWB 测距的核心原理：

  1. 飞行时间（ToF, Time of Flight）： 车辆发送一个脉冲信号，精确记录发送时间 T1；钥匙收到后回复，车辆记录收到时间 T4。扣除钥匙的处理时间（T3-T2），得到信号在空中的飞行时间。
  2. 距离 = 飞行时间 × 光速 — 因为无线电波速度≈光速（3×10⁸ m/s），1纳秒≈30厘米。2米距离的飞行时间只有约6.7纳秒。
  3. 中继攻击为什么失效： 中继器即使以光速转发，每增加1米中继线缆就会增加约3.3纳秒的飞行时间。任何物理中继都会让距离读数变大——如果车设置"距离<2米才解锁"，中继攻击的距离读数可能是10米、100米，直接拒之门外。

关键数据：

参数数值
UWB 测距精度±5~10 厘米
测距更新率10~100 Hz
抗多径能力极强（短脉冲不受反射影响）
防中继攻击✅ 物理原理级防护

CCC 数字钥匙的"三步验证"：

  1. BLE 连接 — 手机靠近车辆时，通过 BLE 建立通信链路，交换能力信息
  2. UWB 测距 — 在认证之前，先通过 UWB 精确测量手机到多个锚点的距离
  3. 加密认证 + 距离验证 — 只有距离在安全阈值内（通常<2米），才进行加密认证和门锁动作

六、三条核心规则

#规则一句话
1中继攻击的本质是"距离欺骗"小偷不破解密码，只是把钥匙的响应信号"接力"到车旁边——系统以为钥匙就在附近，实际上钥匙远在几百米外
2UWB 靠"飞行时间"终结中继攻击精确测量信号从车到钥匙的往返时间 → 距离 = 时间 × 光速。任何中继都会增加飞行时间，被系统识别为"距离太远"
3安全三件套：BLE 建链 + UWB 测距 + 加密认证三个步骤缺一不可。CCC 标准要求测距在认证之前完成（先证明"你在附近"，再证明"你是你"）
