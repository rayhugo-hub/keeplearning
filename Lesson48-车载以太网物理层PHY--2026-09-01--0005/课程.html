一、先想想这个场景

你家里那根网线：RJ45 水晶头 + 8 根芯线（4 对），又粗又硬。电脑后面插一根无所谓。

但车不一样：

  • 一辆智能汽车里，摄像头、域控、传感器之间的以太网线加起来有几十根甚至上百根；
  • 每根都像家里网线那么粗 → 线束比发动机还重，油耗/电耗全被线吃掉；
  • 摄像头装在 A 柱、后视镜上，接口比摄像头本体还大，根本塞不进去；
  • 更麻烦的是电磁干扰：电机、点火、大电流线束都是"噪声源"，普通网线那点抗干扰能力在车里活不过三天。

于是工程师问了一个反常识的问题：

能不能只用 1 对线（2 根芯），就把 1Gbps 的数据"塞"进去，还抗得住车里的电磁干扰？
这一课讲清楚：车载以太网物理层（PHY）——用"单对双绞线 + PAM3 三电平 + 回声消除"三招，让最少的线传最快的数，还最抗干扰。

二、为什么普通网线"进不了车"？

对比项普通以太网（办公室）车载以太网（车内）
线对数1000BASE-T 要 4 对线（8 芯）1 对线（2 芯）
接口RJ45，宽约 16mm小型连接器（MATEnet、H-MTD 等），几毫米
环境温度0~40℃ 空调房-40℃ ~ +105℃（发动机舱更热）
电磁环境干扰少电机、点火、大电流，强干扰
寿命/振动几年、不动十几年、持续振动
减重——整车线束可减重数公斤

结论：普通以太网的物理层是为"办公桌"设计的，车载必须重新发明一套"瘦身+抗造"的物理层。

三、车载以太网"三兄弟"：100BASE-T1 / 1000BASE-T1 / 10BASE-T1S

标准速率调制符号率拓扑 / 距离典型场景
100BASE-T1（802.3bw）100 MbpsPAM366.7 MBd点对点，≤15m诊断口、OTA、低带宽传感器
1000BASE-T1（802.3bp）1 GbpsPAM3750 MBd点对点，≤15m摄像头视频流、域控主干、ADAS
10BASE-T1S（802.3cg）10 MbpsPAM312.5 MBd多点总线 ≤25m / 点对点 15m灯、开关、门锁等边缘节点（替代 CAN/LIN）

三个都是单对双绞线，差别在速率、距离和拓扑：

  • 100BASE-T1 和 1000BASE-T1 是点对点——一根线只连两个设备（如摄像头 → 域控）；
  • 10BASE-T1S 是多点总线——一根线上可以挂最多 8 个节点，不需要交换机，像 CAN 总线一样"共用一条线"。

四、PAM3：三电平的"摩尔斯电码"

问题：1 对线凭什么比 4 对线传得还快？

关键在编码方式——PAM3（三电平脉冲幅度调制）：

编码电平数每符号携带信息类比
NRZ（普通两电平）2 种（0 / 1）1 bit开关：只有"开/关"两档
PAM33 种（-1 / 0 / +1）约 1.58 bit油门：轻踩 / 不踩 / 重踩

类比： 同样的"踩踏板次数"（符号率），两档开关只能表达"开/关"两个意思；三档油门能表达"轻/中/重"三个意思——信息量多了近 60%。

所以：

  • 1000BASE-T1 用 750 MBd 符号率 × PAM3，单对线就能到 1Gbps；
  • 而普通千兆以太网靠 4 对线 × 两电平 NRZ 才凑够同样的带宽。
一句话：车载以太网不是"线更多"，而是"每个符号装的信息更多"。

五、单对线怎么同时收发？——全双工 + 回声消除

问题：只有一对线，发送和接收共用两根芯，怎么同时双向传？

两个设备同时往同一根线上"喊话"，信号会混在一起——怎么分清哪句是对方说的？

答案是 回声消除（Echo Cancellation）：

flowchart LR TX["本端发送信号 TX<br>（自己完全知道内容）"] MIX["混合电路<br>（收发共用一对线）"] ECHO["接收路径混入<br>自己的回声 TX'"] EC["回声消除器<br>用 TX 做参考，减去 TX'"] RX["剩下的就是<br>对方发来的信号"] TX --> MIX --> ECHO --> EC --> RX TX -. 参考信号 .-> EC

原理三步：

  1. 本端发送的信号会"漏"回自己的接收路径，形成回声；
  2. 但本端完全知道自己刚发了什么（发送序列是已知的）；
  3. 回声消除器用"已知的发送序列"做参考，把接收信号里属于自己的部分精确减掉，剩下的就是对方发来的信号。

类比： 同一条电话线上两个人同时说话——你听到自己的声音，知道"这是我说的"，自动屏蔽掉，只留对方的声音。耳机主动降噪也是同一思路：已知噪声长什么样，就把它反相抵消。

关键：回声消除能成立，靠的是"发送内容已知 + 信号线性叠加"——这正是数字通信能精确保证的。

六、上电先"握手"：链路训练（Master/Slave）

PHY 上电后不能立刻传数据，要先"自我介绍"：

  1. 定主从（Master/Slave）——谁是时钟基准，避免两个设备各按各的节奏发信号；
  2. 校准发送电平——把信号幅度调到对方能"舒适接收"的范围；
  3. 训练接收均衡器——让接收端学会"抵消线缆带来的失真"，通信质量达到最佳。

类比： 两个人打电话，接通后先"喂？喂？听得到吗？声音清楚吗？"——确认好了才开始正经说话。

1000BASE-T1 通过训练帧（training frames）完成这个过程，通常在毫秒级完成。

七、EMC：为什么车载以太网抗干扰？

车里是"电磁战场"（电机、点火、大电流线束），物理层必须既抗得住干扰、又不辐射干扰别人。四件武器：

武器原理效果
差分信号两根线互为镜像（一根 +、一根 −），干扰同时落在两线上接收端相减抵消（共模抑制）
双绞两根线不断绞合，受到的干扰更均匀配合差分，干扰进一步抵消
PAM3 紧凑频谱同样速率下带宽占用更小辐射更低，不易干扰别的线束
车规测试大电流注入（BCI）、辐射抗扰（ISO 11452 系列）出厂前验证"抗造"能力

另外还有屏蔽（STP）与非屏蔽（UTP）之分：屏蔽线抗扰更强但更贵更重，非屏蔽更便宜轻便——整车厂按区域电磁环境选型。

八、PHY 在协议栈的哪里？

上一课讲的 TSN 调度在数据链路层（二层），而 PHY 是最底层（物理层，一层）——它是"电信号"和"数据帧"之间的翻译官。

flowchart TB subgraph STACK["车载以太网协议栈"] APP["应用层<br>（SOME/IP 服务、诊断、OTA）"] TP["传输层<br>（TCP / UDP）"] NET["网络层<br>（IP）"] MAC["数据链路层 MAC<br>（帧、VLAN、TSN 调度）"] PHY["物理层 PHY<br>（PCS 编码 / PMA 信号 / PMD 介质）"] APP --> TP --> NET --> MAC --> PHY end WIRE["单对双绞线<br>（差分信号 ±）"] PHY --> WIRE

PHY 内部还分三个子层：

  • PCS（物理编码子层）：把数据编码成 PAM3 符号（"翻译"）；
  • PMA（物理介质附加子层）：把符号变成实际的电信号（"发声"）；
  • PMD（物理介质相关子层）：负责和双绞线这个"介质"对接（"贴着嘴说话"）。

九、三条铁律（记住这三句）

  1. 车载以太网用"单对双绞线"，靠 PAM3 三电平"多装信息"——不是线更多，而是每个符号装的信息更多。
  2. 一对线同时收发靠"回声消除"——自己发的信号自己知道，精确减掉自己的"回声"，剩下的就是对方的声音。
  3. 选型看拓扑：100BASE-T1 / 1000BASE-T1 点对点传大流量，10BASE-T1S 多点总线管边缘小节点——一车以太网，从骨干铺到末梢。
