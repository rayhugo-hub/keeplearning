Lesson 15 — 答案

车载网关的网络安全——网关如何守住汽车的第一道防线？— 参考答案

费曼简答题参考答案

Q1（为什么叫"第一道防线"？攻破后能做什么？）

参考答案方向：

车载网关是连接"外部世界"（4G/Wi-Fi/蓝牙）和"内部网络"（CAN 总线）的唯一通道。所有外部数据——导航地图更新、App 远程控车、OTA 固件下载——都必须经过网关才能进入内部网络。就像一个城堡的唯一大门：大门坚固，城堡安全；大门失守，敌人长驱直入。

攻破网关后能做什么：

  • 向 CAN 总线发送伪造的刹车/加速/转向指令——控制车辆行驶
  • 收发门锁、车窗、空调信号——控制车身功能
  • 读取或修改 ECU 固件——永久驻留攻击代码
  • 利用 4G 连接把车变成僵尸网络节点——发起 DDoS 攻击

Q2（三个层面的防御方案）

参考答案方向（纵深防御）：

层面一句话具体做什么
第一层：外部通信安全（入口防守）确保外部进不来所有外部通信使用 TLS/DTLS 加密；只有经过认证的云平台才能发送数据到网关；T-BOX 和网关间建立安全通道
第二层：网关访问控制（中间防守）进来了也动不了关键系统防火墙 ACL 规则明确禁止外部域访问动力/底盘域；部署 IDS 监控 CAN 总线上的异常行为
第三层：固件/软件安全（底层防守）想改固件也不行Secure Boot 层层验证确保固件未被篡改；OTA 更新验证数字签名并防回滚；HSM 隔离关键密钥操作

三者关系：层层递进——一层破还有下一层。攻破 Wi-Fi 加密（第一层）还有防火墙阻挡（第二层），绕过防火墙还有 Secure Boot 保护固件不被篡改（第三层）。

Q3（为什么家用 IT 防火墙不能直接搬到车上？）

参考答案方向（至少三个本质区别）：

区别家用 IT 网络汽车网关网络
协议差异纯 IP 网络（TCP/UDP），防火墙直接过滤 IP 包"混合网络"——外部是 IP，内部是 CAN/CAN FD/LIN。防火墙需要理解多种协议并做跨协议策略
实时性要求网页加载慢 100ms 用户忍一忍刹车信号延迟 1ms 就可能出人命。IT 防火墙的深度包检测（DPI）会引入不可接受的延迟
安全后果数据泄露、勒索软件人身安全——攻击 CAN 总线可能导致车辆失控
生命周期路由器用 3~5 年就换了汽车寿命 10~15 年，网关要有长达 15 年的安全维护能力
物理安全路由器放家里，一般没人碰OBD-II 接口在车内，任何人都可以物理插上诊断仪绕过软件防火墙

一句话：IT 防火墙处理"纯 IP 包"，而汽车网关要处理"IP→CAN帧"协议转换+实时控制+人身安全，不能简单套用。

选择题答案

题号答案解析
1 B 2015 Jeep 事件的关键教训是：攻击者攻破 T-BOX/网关后，可以直接向 CAN 总线发送任意控制指令（刹车、转向、加速等），证明了网关安全对整车安全的决定性作用。A❌ 与刹车设计无关；C❌ 攻击路径是 4G（Sprint 网络），不是 Wi-Fi；D❌ 即使不用 4G，Wi-Fi/蓝牙/OBD-II 也是攻击入口。
2 B 防火墙（ACL）的核心功能是根据来源网络域→目标网络域的规则决定是否允许消息通过。特别是禁止不可信域（T-BOX/Wi-Fi/蓝牙/OBD）直接访问高安全域（动力 CAN FD、底盘域）。A❌ 防火墙不是阻止"所有"消息，而是有选择性阻止；C❌ 加密不是防火墙的主要功能；D❌ 检测疲劳驾驶是 DMS 的功能。
3 B Secure Boot 的核心是信任链——从硬件 BootROM 开始，每一级启动前都验证下一级固件的数字签名。只有签名通过才能运行，确保网关运行的代码是 OEM 官方发布的、未被篡改的版本。A❌ 每次启动都从云端下载固件不现实；C❌ Secure Boot 不验证"车主"身份；D❌ 自动连 Wi-Fi 不是 Secure Boot 的功能。
